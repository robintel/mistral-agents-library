# x86-64 assembly dialect

Attaches for .S files, inline asm, and disassembly reading. The ABI
is the contract; the rest is idiom.

## Eras

The ISA accreted: the practical era markers are the SIMD generations
(SSE -> AVX -> AVX-512) and the syntax war — AT&T (`gas`) versus
Intel (`nasm`/disassembly default). Write the syntax the repo and
toolchain use; operand order is the giveaway and the classic bug:
AT&T is source, destination; Intel is destination, source.

## The ABI (System V AMD64)

- Integer args in rdi, rsi, rdx, rcx, r8, r9; return in rax. Floats
  in xmm0-7; al carries the vector-arg count for varargs.
- Callee-saved: rbx, rbp, r12-r15. Everything else is yours to save
  if you value it.
- Stack 16-byte aligned at every call — misalignment crashes aligned
  SSE moves at exactly the wrong time.
- The red zone (128 bytes below rsp) is valid in leaf functions and
  absent in signal and interrupt contexts.

## Idiom

- RIP-relative addressing for position-independent code;
  `lea symbol(%rip), %rdi`.
- Linux syscalls: rax the number, rdi rsi rdx r10 r8 r9 the args.
- Frame pointers optional in application code; mandatory-ish in
  stack walking and debugging contexts.

## Pitfalls

- AT&T versus Intel operand order: the number one reading mistake.
- Misaligned stack meeting movaps: the crash that works until it
  doesn't.
- Assuming the red zone in interrupt or signal handlers.
- rep movsb versus SIMD copies: measure — modern CPUs made rep
  competitive again at sizes; folklore lags hardware.
